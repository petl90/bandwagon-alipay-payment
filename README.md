## 搬瓦工支付宝付款时的几个注意事项

### 支付金额不是固定人民币价格

官网套餐以美元标价，支付宝结算时会换算为人民币。人民币金额可能受到汇率变化、支付宝收银台规则以及订单时间影响。不要根据其他文章中的人民币价格判断当前应付金额。

### 优惠码不能随便相信

网上经常能看到“长期循环折扣”“永久优惠码”等说法，但优惠码可能失效、限制特定套餐，或者只适用于首次购买。当前没有可靠依据时，不要把某个历史优惠码写进预算。最稳妥的做法是，在 Checkout 页面输入优惠码后点击验证，只有订单金额真的发生变化，才算优惠生效。

### 付款前确认付款周期

年付看起来便宜，但一次性支出更高；月付灵活，却可能导致长期成本更高。可以按下面的思路选择：

- 只是测试：先选月付或低价年付入门方案；
- 已经确定长期使用：比较半年付和年付总价；
- 业务正在增长：先看流量、内存和迁移条件，不要只看首期价格；
- 需要特定机房：先确认库存，再比较计费周期。
